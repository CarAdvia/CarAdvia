Suppression du compte CarAdvia

Cette page permet aux utilisateurs de CarAdvia de demander la suppression de leur compte et des données associées.

Comment supprimer votre compte

Si vous utilisez CarAdvia, vous pouvez supprimer votre compte directement depuis l'application :

Paramètres → Supprimer mon compte

Demande de suppression via le Web

Si vous ne pouvez pas accéder à l'application, vous pouvez demander la suppression de votre compte en contactant CarAdvia à l'adresse e-mail utilisée pour le service.

Lors de votre demande, indiquez l'adresse e-mail associée à votre compte CarAdvia afin que nous puissions identifier le compte concerné.

Données supprimées

Lorsqu'un compte est supprimé, les données associées au compte sont supprimées conformément au fonctionnement de CarAdvia.

Cela comprend notamment :

  • Le compte utilisateur
  • Les informations du profil
  • Les véhicules enregistrés
  • Les dépenses
  • Les données de carburant
  • Les réparations
  • Les rappels d'entretien
  • Les informations de partage associées au compte

Suppression définitive

La suppression du compte est définitive. Une fois la suppression effectuée, le compte et les données associées ne peuvent pas être récupérés.
